# گوبی‌ها

بازی ادغام — صفحه ۳×۳.

**بازی:** https://nobodyknowkj.github.io/goobies-merging-game-fa/

دو گوبی هم‌شکل را به هم بزن تا ادغام شوند: گوبی پروانه‌ای ← گوبی پلیس ← چیکا ← بانی ← فاکسی ← فردی.

صدا فقط موقع مرج پخش می‌شود؛ هر کاراکتر صدای مرج مخصوص خودش را دارد.

دو مود: معمولی (با رسیدن به فردی بازی تمام می‌شود) و بی‌نهایت/رکوردی (فردی پایان بازی نیست). وقتی فقط یک کاراکتر مانده باشد یا چند کاراکتر غیرقابل‌مرج مانده باشند، همه‌ی خانه‌های خالی یکجا پر می‌شوند.
