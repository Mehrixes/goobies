# گوبی‌ها: بازی ادغام — Five Nights at Goobies

نسخه وب قابل‌بازی ریل اینستاگرام
[instagram.com/reel/DfbfI9qRHbJ](https://www.instagram.com/reel/DfbfI9qRHbJ/)

**زنده:** https://nobodyknowkj.github.io/goobies-merging-game-fa/

## بازی

- صفحه ۳×۳ سفید با خط‌های سیاه، مثل ریل.
- **تو بازی می‌کنی:** هر چند ثانیه یک گوبی پروانه‌ای ظاهر می‌شود. روی یک گوبی بزن، بعد روی یک گوبی هم‌شکل دیگر بزن تا ادغام شوند و به مرحله بالاتر برسند.
- مراحل: گوبی پروانه‌ای ← گوبی عینکی ← گوبی پلیس ← چیکا ← بانی ← فاکسی ← **گوبی طلایی 👑**
- اگر صفحه پر شود و هیچ دو گوبی هم‌شکلی نماند، بازی تمام است.
- دکمه «فقط تماشا کن» فقط برای دیدن گیم‌پلی است (مثل ریل)؛ در آن حالت نمی‌توانی روی خانه‌ها بزنی.

## صداها — جذابیت اصلی بازی

همه صداها با WebAudio ساخته شده‌اند، بدون هیچ فایل صوتی:

- **ادغام:** زنگ نرم و آرام‌بخش — سه نت ملایم از گام پنتاتونیک با کشش طولانی؛ هر مرحله بالاتر، یک پرده بالاتر و لطیف‌تر.
- ظاهر شدن: پاپ نرم • انتخاب: کلیک ملایم • خطا: بَز کوتاه و ملایم • برد: فانفار آرام • باخت: ملودی پایین‌رونده
- موزیک: بازسازی لوپ تند ریل، پیش‌فرض **خاموش** و با صدای کم — چون زنگ ادغام ستاره است.

ریل اصلی صدای جداگانه بازی نداشت و خودش هم قابل‌بازی‌کردن نبود (فقط انیمیشن ۲۶ ثانیه‌ای)؛ قوانین، امتیاز و صداها برای نسخه وب ساخته شده‌اند.

## اجرا

فقط `index.html` را در مرورگر باز کن. بدون سرور، بدون ذخیره‌سازی؛ فقط بهترین امتیاز روی همین دستگاه ذخیره می‌شود.
