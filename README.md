## بازی

- صفحه ۳×۳ سفید با خط‌های سیاه، مثل ریل.
- **تو بازی می‌کنی:** هر چند ثانیه یک گوبی پروانه‌ای ظاهر می‌شود. روی یک گوبی بزن، بعد روی یک گوبی هم‌شکل دیگر بزن تا ادغام شوند و به مرحله بالاتر برسند.
- مراحل: گوبی پروانه‌ای ← گوبی عینکی ← گوبی پلیس ← چیکا ← بانی ← فاکسی ← **گوبی طلایی 👑**
- اگر صفحه پر شود و هیچ دو گوبی هم‌شکلی نماند، بازی تمام است.
- دکمه «فقط تماشا کن» فقط برای دیدن گیم‌پلی است (مثل ریل)؛ در آن حالت نمی‌توانی روی خانه‌ها بزنی.

## صداها — جذابیت اصلی بازی

**صدا فقط موقع مرج کردن پخش می‌شود — یکسره پخش نمی‌شود.** ظاهر شدن گوبی، انتخاب کردن و اشتباه زدن هیچ صدایی ندارند و هیچ موزیک پس‌زمینه‌ای نیست.

- **ادغام:** همان «بِ» واقعی فایل صوتی ریل — هر کاراکتر صدای مرج مخصوص خودش را دارد. فایل ۳۰ ثانیه‌ای ریل ۳۸ تا «بِ» کوتاه حدود ۰٫۴۵ ثانیه‌ای داشت با زیر و بمی‌های متفاوت (حدود ۵۰۳، ۶۰۰، ۷۶۰ و ۱۰۱۰ هرتز)؛ چهار برش تمیز از آن‌ها در خود `index.html` جاسازی شده است (base64) و برای فاکسی و گوبی طلایی همان «بِ» ۱۰۱۰ هرتزی یک پرده بالاتر پخش می‌شود.
- روی هر کاراکتر در جدول مراحل — یا روی دکمه‌های بخش «صدای مرج» — بزن تا صدای مرج مخصوص همان کاراکتر را بشنوی.

ریل اصلی خودش قابل‌بازی‌کردن نبود (فقط انیمیشن ۲۶ ثانیه‌ای)؛ قوانین، امتیاز و پایان بازی برای نسخه وب ساخته شده‌اند.

## اجرا

فقط `index.html` را در مرورگر باز کن. بدون سرور، بدون ذخیره‌سازی؛ فقط بهترین امتیاز روی همین دستگاه ذخیره می‌شود.
